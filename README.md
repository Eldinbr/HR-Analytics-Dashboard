Project Title: **HR-Analytics-Dashboard**

An interactive HR Analytics Dashboard built in Tableau Public. This project analyzes employee attrition, workforce demographics, job satisfaction, and employee age distribution to uncover trends that support data-driven HR decision-making. The dashboard highlights key HR metrics such as attrition rate, department-wise attrition, gender-based insights, and employee satisfaction patterns.

Tableau Dashboard Link : https://public.tableau.com/app/profile/eldin.b.joseph/viz/HRAnalyticsDashboard_17238387531440/HRAnalyticsDashboard

## Overview

- **Motivation:** Human Resources teams often struggle to identify patterns behind employee attrition and workforce satisfaction. This project was created to visualize HR data in an interactive way that helps organizations better understand employee behavior and improve retention strategies.
- **Objective:** The main objectives of this dashboard are: The main objective of this dashboard is to analyze employee attrition, workforce demographics, and job satisfaction trends across departments and roles to support data-driven HR decision-making.
- **Learning Outcomes:** While building this project, I learned Tableau dashboard design, data cleaning and transformation, creating interactive visualizations, analyzing workforce and attrition patterns, and presenting business insights effectively through dashboards.

## Dataset

Dataset Information

- Dataset Type: HR Employee Dataset  
- Records: 1,470 employees 
- Features Included: Employee Attrition Department
Gender
Age
Education Field
Job Satisfaction
Job Role
Employee Count 
- The dataset was cleaned and transformed before visualization:
Removed duplicate and null values
Standardized categorical columns
Grouped employees by age ranges
Calculated attrition rate and active employee metrics
Prepared aggregated values for dashboard visualizations

## Analysis & Visualizations 

Key Insights

- The organization has an attrition rate of 16.12%
- Research & Development shows the highest employee attrition
- Employees aged between 26–35 years show higher attrition trends
- Male employees have a higher attrition count compared to female employees
- Sales Executives and Research Scientists represent large employee groups
- Job satisfaction varies significantly across job roles 

Business Value

- Improve employee retention strategies
- Identify high-risk departments
- Understand workforce satisfaction trends
- Support strategic hiring and workforce planning
