**HR-Analytics-Dashboard**

An interactive HR Analytics Dashboard built in Tableau Public. This project analyzes employee attrition, workforce demographics, job satisfaction, and employee age distribution to uncover trends that support data-driven HR decision-making. The dashboard highlights key HR metrics such as attrition rate, department-wise attrition, gender-based insights, and employee satisfaction patterns.

**Overview**

Motivation:

Human Resources teams often struggle to identify patterns behind employee attrition and workforce satisfaction. This project was created to visualize HR data in an interactive way that helps organizations better understand employee behavior and improve retention strategies.

Objective:

The main objectives of this dashboard are:
Analyze employee attrition trends
Identify departments with higher attrition rates
Explore demographic distributions such as age and gender
Understand job satisfaction levels across job roles
Support HR professionals in making informed decisions

Learning Outcomes:

While building this project, I learned:
Tableau dashboard design and storytelling
Data cleaning and transformation techniques
Creating interactive visualizations and filters
Analyzing workforce and attrition patterns
Presenting business insights through dashboards

**Installation**

To explore this project locally:

git clone https://github.com/eldinbr/HR-Analytics-Dashboard.git

cd HR-Analytics-Dashboard
Open the Tableau workbook file (.twb / .twbx) using Tableau Public or Tableau Desktop.

**Usage**

Download or clone the repository
Open the Tableau workbook file
Interact with filters and charts
Explore HR metrics and attrition insights
The dashboard allows users to:
Filter data by education level
Compare attrition trends across departments
Analyze job satisfaction by role
Understand workforce demographics interactively

**Analysis & Insights**

Key Insights:

The organization has an attrition rate of 16.12%
Research & Development shows the highest employee attrition
Employees aged between 26–35 years show higher attrition trends
Male employees have a higher attrition count compared to female employees
Sales Executives and Research Scientists represent large employee groups
Job satisfaction varies significantly across job roles

Business Value:

This dashboard can help HR teams:
Improve employee retention strategies
Identify high-risk departments
Understand workforce satisfaction trends
Support strategic hiring and workforce planning
