# HR-Analytics-Dashboard
Interactive HR Analytics Dashboard built in Tableau Public. Analyzes employee attrition, demographics, job satisfaction, and age distribution. Highlights key metrics like attrition rate, department trends, and gender insights to support data-driven HR decisions.
